当前卡片仅展示已审核的公开产品；简介及网站入口由源码项目的 `src/public/projects.ts` 维护并随构建同步，此仓不复制卡片数据表。项目授权与内容使用以各自仓库声明为准。页面依赖的许可证见 THIRD_PARTY_NOTICES.txt；不以仓库可公开访问代替授权声明。
