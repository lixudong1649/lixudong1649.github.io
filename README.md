本仓库仅维护经检查的静态个人主页发布产物，开发源码由独立仓库维护。首版展示 GitHub 入口、审核后的公开项目卡片与 Wiki，不包含个人联系方式、经历、资料编辑配置或账号密钥。

GitHub Pages 使用 main 分支根目录，index.html 为首页，.nojekyll 跳过 Jekyll 构建。assets 中的文件由构建生成，不手工修改；更新须在源码项目构建和检查后同步。

当前卡片展示经过审核的公开源码项目与公开演示，分别标注源码可见性；私有项目只提供演示入口，不公开仓库链接。简介及网站入口由源码项目的 `src/public/projects.ts` 维护并随构建同步，此仓不复制卡片数据表。项目授权与内容使用以各自仓库声明为准。页面依赖的许可证见 THIRD_PARTY_NOTICES.txt；不以仓库可公开访问代替授权声明。
