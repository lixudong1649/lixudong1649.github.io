Skill 盘点：文件数为何不等于可用技能数 ​

先问清楚要统计磁盘文件、插件登记，还是当前会话可用能力。基本定义见 Agent Skill。

三个容易误判的地方 ​

  • 同一技能可能同时存在于共享目录、软链接与插件缓存，不能简单相加。
  • 同一插件可能留有多个版本，旧缓存不是当前启用证据。
  • 示例、模板与只读上游目录可能含 SKILL.md，不等于宿主会加载它们。

从小范围开始 ​

先检查用户明确选定的目录和当前项目，再查已知插件层级。保留目录状态、技能名、真实路径和来源；缺目录、权限不足与无匹配分别记录。

可用下面的命令观察一个明确授权目录中的技能文件。<approved-directory> 为占位，需要替换；该命令只列文件，不执行技能。

bash
rg --files --hidden <approved-directory> -g SKILL.md

这不是完整的宿主安装扫描器，忽略规则、软链接和自定义目录会影响结果。需要深入盘点时按固定插件层级解析，不无边界递归整个磁盘。

对照宿主，而不是替宿主下结论 ​

再核对插件登记、启用设置和当前会话清单；代表任务成功只证明特定环境下能执行。输出先给分组数量，再按需展开必要明细，避免数百条路径把结果截断。

盘点输出可能暴露用户名、插件名和项目路径，留在本机临时目录；公开文章只保留方法，不上传真实盘点清单。

参考：Agent Skills 规范。本文是盘点经验整理，不保证每个宿主采用同一目录布局；整理：2026-10-14。
